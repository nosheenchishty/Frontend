# Settings & Preferences

Standalone React demo for theming, privacy controls, language preferences, and save-reset settings flows.

## Stack

- React 18
- Vite 5
- ESLint 9

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`

## Boilerplate Focus

- Clear component state boundaries
- Readable, production-friendly structure
- Easy handoff into a real project codebase
