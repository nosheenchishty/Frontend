# Search & Filtering

Standalone React demo for searchable listings with filters, sorting controls, and zero-result handling.

## Stack

- React 18
- Vite 5
- ESLint 9

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`

## Boilerplate Focus

- Clear component state boundaries
- Readable, production-friendly structure
- Easy handoff into a real project codebase
